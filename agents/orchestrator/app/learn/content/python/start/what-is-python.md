## Why people start with Python

Most languages make you learn rules about the computer before you can do anything useful. Python lets you start with the idea. This is a complete program:

```python
print("Hello, SkillDARA!")
```

```output
Hello, SkillDARA!
```

One line, one result. That small distance between an idea and a working program is why Python is the first language in many colleges.

## What Python is used for

| Area | Example |
| --- | --- |
| Web | Back ends for sites and APIs (Flask, Django) |
| Data | Cleaning and analysing tables (Pandas, NumPy) |
| AI and ML | Training models (scikit-learn, PyTorch) |
| Automation | Renaming files, sending reports, scraping pages |
| Testing | Checking that other software works |

:::note
Python is **interpreted**: the Python program reads your file and runs it line by line. You do not compile it first, so you can try an idea and see the result straight away.
:::

## How a Python program runs

1. You write instructions in a file ending in `.py`.
2. You ask Python to run the file.
3. Python reads the first line, does it, then the second, and so on.

If a line is wrong, Python stops and tells you which line and why. Reading those messages is a skill you will build as you go.

:::interview
**Interviewers often ask:** "Is Python compiled or interpreted?" A safe answer: Python source is compiled to bytecode and then executed by the interpreter, so in everyday use we call it an interpreted language.
:::
