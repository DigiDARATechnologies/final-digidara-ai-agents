title: Analogies and odd one out
summary: Find the relationship in a pair and apply it, and spot the item that does not belong, for words, numbers and letters.
takeaways:
- First name the relationship in the example pair, then apply the same one
- Common relations: part and whole, tool and user, category, degree, cause and effect
- For odd one out, find the property shared by all the others
---
## Word analogies

Format: **A : B :: C : ?** (A is to B as C is to ?).

Steps: say the relationship in a sentence, then use the **same sentence** on C.

| Relationship | Example |
| --- | --- |
| Part to whole | Petal : Flower :: Page : Book |
| Tool to user | Stethoscope : Doctor :: Chisel : Sculptor |
| Category | Rose : Flower :: Python : Language |
| Opposite | Hot : Cold :: Rise : Fall |
| Degree | Warm : Hot :: Cool : Cold |
| Cause and effect | Fire : Smoke :: Rain : Flood |
| Place of work | Teacher : School :: Doctor : Hospital |
| Product to source | Wool : Sheep :: Milk : Cow |

:::example
Pen : Write :: Knife : ?

**Solution.** A pen is used to write, so a knife is used to **cut**.
:::

## Number analogies

:::example Cube
3 : 27 :: 4 : ?

**Solution.** 27 = 3 cubed, so the answer is 4 cubed = **64**.
:::

:::example
5 : 30 :: 7 : ?

**Solution.** 5 x 6 = 30 (the number times the next number), so 7 x 8 = **56**.
:::

## Letter analogies

:::example Shifting letters
ACE : BDF :: GIK : ?

**Solution.** Each letter moves one step forward (A to B, C to D, E to F). So G to H, I to J, K to L: **HJL**.
:::

:::example Reversal
CAT : TAC :: DOG : ?

**Solution.** The word is reversed, so **GOD**.
:::

## Odd one out

Find what is common to most items and pick the one that breaks the rule.

:::example Numbers
Which is the odd one out: 8, 27, 64, 100, 125?

**Solution.** 8, 27, 64 and 125 are perfect cubes (2, 3, 4 and 5 cubed). **100** is not.
:::

:::example Words
Which is the odd one out: Apple, Mango, Potato, Banana?

**Solution.** The others are fruits. **Potato** is a vegetable.
:::

:::example Letters
Which is the odd one out: BDF, HJL, PRT, MNO?

**Solution.** In BDF, HJL and PRT each letter is 2 steps after the previous one (B, D, F and so on). In MNO each letter is only 1 step after the previous one. The odd one out is **MNO**.
:::

:::tip
Write the relationship as a full sentence ("A is used for B") before looking at the options. It prevents being fooled by options that are related but in a different way.
:::
