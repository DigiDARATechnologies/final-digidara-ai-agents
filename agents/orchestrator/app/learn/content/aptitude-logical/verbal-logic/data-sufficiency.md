---
title: Data sufficiency
summary: Decide whether the given statements are enough to answer a question, without necessarily solving it.
takeaways:
- You only decide if the data is enough; you do not need the final answer
- Test each statement alone, then both together
- A statement that gives two different answers is not sufficient
---
## The format

A question is followed by two statements, I and II. The usual options:

| Option | Meaning |
| --- | --- |
| A | Statement I alone is sufficient |
| B | Statement II alone is sufficient |
| C | Both together are sufficient, but neither alone |
| D | Each statement alone is sufficient |
| E | Neither alone nor together is sufficient |

(The order can change; read the options in your test.)

## Method

1. Read the **question** and decide exactly what you need to find.
2. Check **I alone**: can you get **one** definite answer?
3. Check **II alone** the same way, forgetting I.
4. If neither works alone, check **both together**.
5. If still no single answer, the data is insufficient.

:::example A number
**Question:** What is the value of x?
I. 2x = 10.
II. x is a prime number greater than 4.

**Solution.** I gives x = 5, one definite value, so I is sufficient. II allows 5, 7, 11, ... many values, so II is not sufficient. Answer: **I alone is sufficient**.
:::

:::example Heights
**Question:** Is X taller than Y?
I. X is taller than Z.
II. Z is taller than Y.

**Solution.** I alone: X > Z, nothing about Y. II alone: Z > Y, nothing about X. Together: X > Z > Y, so X is taller than Y. Answer: **both together are needed**.
:::

:::example Age
**Question:** What is Ravi's age?
I. Ravi is 5 years older than Sita.
II. Sita is 20 years old.

**Solution.** I alone is not enough, II alone is not enough. Together Ravi = 25. Answer: **both together**.
:::

:::example Not enough
**Question:** How many students are in the class?
I. 40% of the students are girls.
II. There are 12 more boys than girls.

**Solution.** Let total = T. I: girls = 0.4T, boys = 0.6T. II: 0.6T - 0.4T = 12, so 0.2T = 12, T = 60. I alone: no number. II alone: no total. Together: T = 60. Answer: **both together**.
:::

## Common traps

- Do not use **your own knowledge** or assume extra data.
- A statement that gives "x = 3 or x = -3" is **not** sufficient for "what is x?" but may be sufficient for "what is x squared?".
- For yes/no questions, a statement is sufficient if it always gives **yes** or always gives **no**.

:::remember
You are the examiner of the data, not the solver of the problem. Stop as soon as you know whether the answer is unique.
:::
