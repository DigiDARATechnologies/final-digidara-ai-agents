## What a syllogism is

You get two statements (the **premises**) and some conclusions. You say which conclusions **must** follow, however the circles are drawn. Treat the statements as true even if they sound silly in real life.

## The four statement types

| Statement | Meaning |
| --- | --- |
| All A are B | A sits completely inside B |
| No A is B | the two circles do not touch |
| Some A are B | the two circles overlap at least a little |
| Some A are not B | part of A lies outside B |

## Rules that always hold

| Premises | Valid conclusion |
| --- | --- |
| All A are B, All B are C | All A are C |
| Some A are B, All B are C | Some A are C |
| All A are B, No B is C | No A is C |
| All A are B, Some B are C | **none** about A and C |
| Some A are B, Some B are C | **none** about A and C |

Also, "Some A are B" can be reversed to "Some B are A". "No A is B" can be reversed to "No B is A". But "All A are B" **cannot** be reversed.

## Examples

:::example A chain of "all"
All cats are animals. All animals are living things. Is "All cats are living things" valid?

**Solution.** Cats sit inside animals, which sit inside living things. So cats sit inside living things. **Valid.**
:::

:::example A conclusion that does not follow
All cats are animals. Some animals are pets. Does "Some cats are pets" follow?

**Solution.** Draw cats inside animals. The "pets" circle overlaps animals, but it may or may not touch the cats part. So it **does not definitely follow.** But "Some pets are animals" is the reverse of the second statement, so it **is valid**.
:::

:::example No and all
No A is B. All C are A. Does "No C is B" follow?

**Solution.** C is inside A, and A does not touch B, so C cannot touch B. **Valid.**
:::

## A step-by-step method

1. Draw one circle per term.
2. Place the circles so the first statement is true.
3. Add the second statement, drawing the **loosest** picture that still fits.
4. A conclusion is valid only if it holds in **every** picture you could draw.

:::tip
For "Some" statements, draw a small overlap and also try a picture where the overlap is bigger. If the conclusion fails in either one, it is not valid.
:::

:::remember
Do not use your real-world knowledge. If the statements say "All pens are books", that is true for the question.
:::
