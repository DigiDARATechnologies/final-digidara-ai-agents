- Growth is always divided by the old value
- Check units and whether the question asks for a value or a percent

Enrolments in a training institute (number of students):

| Course | 2023 | 2024 |
| --- | --- | --- |
| Python | 200 | 240 |
| Java | 150 | 135 |
| Data Science | 100 | 180 |
| Web Development | 50 | 45 |
| **Total** | **500** | **600** |

Target: 8 minutes.

:::example Q1. Total
What was the total enrolment in 2024?

**Solution.** 240 + 135 + 180 + 45 = **600**.
:::

:::example Q2. Overall growth
What is the percentage growth in total enrolment from 2023 to 2024?

**Solution.** (600 - 500) / 500 x 100 = **20%**.
:::

:::example Q3. Fastest growth
Which course had the highest percentage growth?

**Solution.**
- Python: 40/200 = 20%
- Java: -15/150 = -10%
- Data Science: 80/100 = 80%
- Web Development: -5/50 = -10%

**Data Science** grew fastest, by 80%.
:::

:::example Q4. Share
What percentage of the 2024 enrolment was in Python?

**Solution.** 240 / 600 x 100 = **40%**.
:::

:::example Q5. Ratio
Find the ratio of Java enrolment in 2023 to Data Science enrolment in 2024.

**Solution.** 150 : 180 = **5 : 6**.
:::

:::example Q6. Average
What was the average enrolment per course in 2023?

**Solution.** 500 / 4 = **125**.
:::

:::example Q7. Pie angle
If the 2024 enrolment were drawn as a pie chart, what angle would Data Science have?

**Solution.** 180 / 600 x 360 = **108 degrees**.
:::

## What to do next

If you made mistakes, note whether they were **calculation slips** (practise mental maths), **misreading** (read the question twice) or **concept gaps** (revisit the lesson).
