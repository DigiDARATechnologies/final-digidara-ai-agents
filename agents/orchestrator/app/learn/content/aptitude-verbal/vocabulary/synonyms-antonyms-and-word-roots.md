## Synonyms and antonyms

- **Synonym**: a word with a **similar** meaning.
- **Antonym**: a word with an **opposite** meaning.

The words below appear again and again in exams.

| Word | Synonym | Antonym |
| --- | --- | --- |
| Abundant | plentiful | scarce |
| Candid | frank, open | secretive |
| Diligent | hardworking | lazy |
| Eloquent | fluent, expressive | inarticulate |
| Frugal | thrifty | wasteful, extravagant |
| Genuine | real, authentic | fake |
| Hostile | unfriendly | friendly |
| Obsolete | outdated | modern |
| Reluctant | unwilling | eager |
| Verbose | wordy | concise, brief |
| Benevolent | kind | cruel, malevolent |
| Conceal | hide | reveal |
| Enhance | improve | reduce |
| Mitigate | reduce, ease | aggravate, worsen |
| Prudent | wise, careful | reckless |
| Ambiguous | unclear | clear, definite |
| Brittle | fragile | flexible, tough |
| Meagre | very small | ample |
| Inevitable | unavoidable | avoidable |
| Vague | unclear | specific |

## Roots, prefixes and suffixes

### Common prefixes

| Prefix | Meaning | Examples |
| --- | --- | --- |
| **un-, in-, im-, dis-, non-** | not | unhappy, incorrect, impossible, dislike |
| **re-** | again | rewrite, rebuild |
| **pre-** | before | preview, prehistoric |
| **post-** | after | postpone, postgraduate |
| **anti-** | against | antibiotic, anticlockwise |
| **auto-** | self | autobiography, automatic |
| **bi-, tri-** | two, three | bicycle, triangle |
| **mis-** | wrongly | misunderstand |
| **sub-** | under | submarine, subway |

### Common roots

| Root | Meaning | Examples |
| --- | --- | --- |
| **bene** | good | benefit, benevolent |
| **mal** | bad | malfunction, malicious |
| **dict** | say | dictate, predict |
| **scrib, script** | write | describe, manuscript |
| **spect** | see | inspect, spectator |
| **port** | carry | transport, import |
| **aqua** | water | aquarium, aquatic |
| **tele** | far | telephone, telescope |
| **chron** | time | chronology, synchronise |
| **phobia** | fear | claustrophobia |

### Common suffixes

- **-able, -ible**: can be (readable, flexible)
- **-ful**: full of (careful); **-less**: without (careless)
- **-ology**: study of (biology); **-cracy**: rule by (democracy)

:::example Guess the meaning
"The company's **malpractice** was exposed."

**Solution.** **mal** means bad, so malpractice is **wrong or improper practice**.
:::

## Choosing the meaning from context

Many words have more than one meaning. Use the **sentence** to decide.

:::example
Choose the word closest in meaning to **MITIGATE**: "Planting trees can mitigate the effects of pollution."
(a) increase (b) reduce (c) ignore (d) cause

**Solution.** The sentence is about making the effects smaller: **(b) reduce**.
:::

## How to learn 10 words a day

1. Learn the word, a **synonym**, an **antonym** and one **sentence of your own**.
2. Revise yesterday's list before adding new words.
3. Read a newspaper editorial daily and note unknown words.
4. Revise weekly using a notebook or flashcards.

:::tip
In antonym questions, first decide the meaning of the given word, then look for the exact opposite. Do not pick a merely different word.
:::
