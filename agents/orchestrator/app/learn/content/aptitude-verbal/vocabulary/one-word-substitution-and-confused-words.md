---
title: One-word substitution and confused words
summary: Replace a long phrase with one exact word, and avoid the pairs of words that look or sound alike.
takeaways:
- One precise word can replace a whole phrase
- Learn them in groups: people, fears, rule, study of
- Confused words: check the meaning before using
---

## Confused words

| Words | Difference |
| --- | --- |
| **accept / except** | accept = receive; except = apart from |
| **affect / effect** | affect (verb) = influence; effect (noun) = result |
| **advice / advise** | advice (noun); advise (verb) |
| **complement / compliment** | complement = completes; compliment = praise |
| **principal / principle** | principal = head or main; principle = rule |
| **stationary / stationery** | stationary = not moving; stationery = writing material |
| **personal / personnel** | personal = private; personnel = staff |
| **site / sight / cite** | place / vision / quote |
| **loose / lose** | loose = not tight; lose = fail to keep |
| **breath / breathe** | breath (noun); breathe (verb) |
| **later / latter** | later = after; latter = the second of two |
| **farther / further** | farther = more distance; further = additional |
| **eminent / imminent** | eminent = famous; imminent = about to happen |
| **ensure / insure** | ensure = make certain; insure = buy insurance |
| **council / counsel** | council = a group; counsel = advice |

:::example
He is an ____ scholar in the field of physics.
(a) imminent (b) eminent (c) immanent (d) emanate

**Solution.** A famous scholar is **(b) eminent**.
:::

:::example
The weather will ____ the match.
(a) effect (b) affect (c) infect (d) defect

**Solution.** "Affect" is the verb meaning influence: **(b) affect**.
:::

:::trick
For "affect/effect", remember **A**ffect is an **A**ction (verb) and **E**ffect is the **E**nd result (noun).
:::
