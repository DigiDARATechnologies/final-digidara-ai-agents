## Formula revision

| Topic | Key formula |
| --- | --- |
| Percentage | x% of y = xy/100; change % = (new - old)/old x 100 |
| Successive change | a%, b% net = a + b + ab/100 |
| Ratio | a : b = a/b; divide the total in the ratio parts |
| Average | sum / count; new average after adding a value |
| Profit and loss | profit % = profit / CP x 100; SP = CP (1 + p/100) |
| Discount | SP = MP (1 - d/100) |
| Simple interest | SI = PRT / 100 |
| Compound interest | A = P (1 + R/100) to the power T |
| Time and work | work = rate x time; combined rate = sum of rates |
| Speed | speed = distance / time; km/h to m/s x 5/18 |
| Trains | crossing platform: (L + P) / speed |
| Boats | downstream b + s; upstream b - s |
| HCF x LCM | = product of the two numbers |
| Mixture | cheaper : dearer = (d - m) : (m - c) |
| Partnership | share is proportional to investment x time |
| nPr, nCr | n!/(n - r)!, n!/(r!(n - r)!) |
| Probability | favourable / total; at least one = 1 - none |
| Circle | area pi r squared; circumference 2 pi r |
| Cylinder | volume pi r squared h |
| Sphere | volume (4/3) pi r cubed |

## Test strategy

1. **Scan** the paper and start with questions you can solve in under a minute.
2. **Skip** a question that needs more than about 2 minutes, and mark it to return to.
3. **Use the options**: sometimes you can test them quickly instead of solving.
4. **Approximate** when options are far apart.
5. **Check units** (minutes or hours, km/h or m/s) before the final answer.
6. Watch for **negative marking**: guess only when you can remove at least two options.

## Build speed

- Learn squares up to 25, cubes up to 10 and fractions to percentages.
- Practise **mental maths** for 10 minutes a day.
- Time yourself: 20 questions in 25 minutes is a typical campus target.
- Keep a notebook of mistakes and revise it weekly.

## Weekly plan

| Day | Focus |
| --- | --- |
| Mon to Wed | one topic per day, learn and solve 15 questions |
| Thu | revise formulas and tricks |
| Fri | mixed timed test of 20 questions |
| Sat | review every mistake |
| Sun | rest or light revision |

:::remember
Accuracy first, then speed. Ten correct answers beat fifteen rushed ones when marking is negative.
:::
