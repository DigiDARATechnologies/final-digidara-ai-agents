## BODMAS

Order of operations: **B**rackets, **O**rders (powers and roots), **D**ivision and **M**ultiplication (left to right), **A**ddition and **S**ubtraction (left to right).

`8 + 6 x 3 - 4 / 2 = 8 + 18 - 2 = 24`

## Squares and cubes to remember

Squares up to 25: 13 -> 169, 14 -> 196, 15 -> 225, 16 -> 256, 17 -> 289, 18 -> 324, 19 -> 361, 20 -> 400, 21 -> 441, 22 -> 484, 23 -> 529, 24 -> 576, 25 -> 625.

Cubes: 2 -> 8, 3 -> 27, 4 -> 64, 5 -> 125, 6 -> 216, 7 -> 343, 8 -> 512, 9 -> 729, 10 -> 1000.

## Identities

:::formula
(a + b) squared = a squared + 2ab + b squared
(a - b) squared = a squared - 2ab + b squared
(a + b)(a - b) = a squared - b squared
:::

:::example Difference of squares
Find 98 x 102.

**Solution.** (100 - 2)(100 + 2) = 100 squared - 2 squared = 10000 - 4 = **9996**.
:::

:::example Squaring near 1000
Find 996 squared.

**Solution.** (1000 - 4) squared = 1,000,000 - 8,000 + 16 = **992,016**.
:::

:::trick
Numbers ending in 5: square of n5 = n x (n + 1) followed by 25. So 65 squared = (6 x 7) then 25 = **4225**.
:::

## Square root of a perfect square

:::example Square root of 5476
**Solution.** It ends in 6, so the root ends in 4 or 6. The part before the last two digits is 54, between 7 squared (49) and 8 squared (64), so the tens digit is 7. Compare 54 with 7 x 8 = 56: since 54 is smaller, choose the smaller ending, 4. The answer is **74** (74 squared = 5476).
:::

## Cube root

:::example Cube root of 17576
**Solution.** Last digit 6, so the root ends in 6. Remove the last three digits to get 17, which lies between 2 cubed (8) and 3 cubed (27), so the tens digit is 2. The root is **26**.
:::

## Approximation

When the question says "approximately", round each number to a friendly one.

:::example
Approximately, what is 49% of 599 + 24.8% of 1001?

**Solution.** 49% of 600 is about 294. 24.8% of 1000 is about 248, so the sum is about **540**. (The exact value is about 541.8.) Choose the nearest option.
:::

## Surds

`sqrt(50) = sqrt(25 x 2) = 5 sqrt(2)`. Also `sqrt(0.0049) = 0.07`.

:::remember
Look for a pattern before multiplying: near 100 or 1000, a perfect square, or a difference of squares.
:::
