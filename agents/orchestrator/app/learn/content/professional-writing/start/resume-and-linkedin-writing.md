## What a resume is for

A resume has one job: to get you **a conversation**. A recruiter may spend only **6 to 10 seconds** on the first look, and many companies use software (ATS, an applicant tracking system) that filters resumes by keywords before any person reads them. So the resume must be **easy to scan** and **specific**.

## The layout

| Section | Content | Tips |
| --- | --- | --- |
| **Header** | name, phone, professional email, city, LinkedIn, GitHub | no photo needed unless asked; no date of birth, religion or father's name |
| **Summary** (optional, 2 lines) | who you are and what you are looking for | skip it if you have nothing specific to say |
| **Education** | degree, college, year, CGPA/percentage | most recent first |
| **Projects** | 2 to 4 best projects | for freshers this is often the strongest section |
| **Skills** | tools and technologies you can really use | group them: Languages, Tools, Databases |
| **Experience / internships** | role, company, dates, achievements | most recent first |
| **Certifications, achievements** | relevant ones only | prizes, competitions, leadership |

Keep it to **one page** as a fresher. Use a simple, standard font (Calibri, Arial), consistent spacing and a clean template. Save as **PDF** with a clear name: `Priya_Nair_Resume.pdf`.

## Write bullets that show results

Do not describe your duties. Show **what you did, how, and what changed**.

**Formula:** action verb + what you did + how/tool + result (number if possible).

| Weak | Strong |
| --- | --- |
| Responsible for analysing sales data. | Analysed 20,000 sales records using Python and SQL; found that 3 cities produced 18% of orders. |
| Worked on a website. | Built a responsive student portal with Flask and MySQL used by 120 students in 4 departments. |
| Helped in organising an event. | Led a 6-member team to organise a college hackathon with 250 participants, 20% above target. |
| Good at communication. | Presented a final-year project to a panel of 5 faculty; awarded best project in the department. |

**Strong action verbs:** built, designed, developed, analysed, improved, reduced, increased, led, organised, automated, tested, launched, presented, trained, resolved.

If you cannot measure the result exactly, use a believable estimate that you can **explain in an interview**. Never invent numbers: interviewers will ask.

## Skills section

| Do | Do not |
| --- | --- |
| list tools you can discuss and use | list everything you have heard of |
| group them clearly | rate yourself with stars or percentages ("Python: 80%") |
| match keywords in the job description (if true) | list "MS Office" as your main skill |

If you list a skill, expect a question about it. A short list you know well beats a long list you do not.

## Common resume mistakes

| Mistake | Fix |
| --- | --- |
| spelling errors and inconsistent formatting | proofread twice; ask a friend |
| a two-page resume with little content | one page, only the best |
| an unprofessional email address | firstname.lastname@... |
| a long "objective" with clichés ("seeking a challenging position to utilise my skills") | delete it, or write a specific summary |
| personal details such as religion, father's occupation | remove |
| false claims | never; they are discovered in interviews and background checks |
| the same resume sent to every job | adjust the summary, skills and project order for each role |

## LinkedIn headline

The headline appears next to your name everywhere. Avoid the default "Student at XYZ College". Say what you do and what you know.

| Weak | Strong |
| --- | --- |
| Student | Final-year B.Tech CSE student | Python | SQL | Data Analytics |
| Looking for opportunities | Aspiring Data Analyst | Excel, SQL, Power BI | Open to internships |

## LinkedIn summary ("About")

Write 3 to 5 short sentences, in the first person, in plain language:

:::example LinkedIn summary
I am a final-year Computer Science student who enjoys turning data into decisions. I have built three projects: a sales dashboard using SQL and Power BI, a student pass-prediction model in Python, and a Flask web app used by 120 classmates. I am looking for a data analyst internship where I can learn from a team and contribute to real problems. You can reach me at priya.nair@email.com.
:::

## Other LinkedIn tips

| Tip | Why |
| --- | --- |
| clear, friendly photo with a plain background | profiles with photos get many more views |
| add projects, skills and certificates | gives recruiters something to search for |
| ask a teacher or an internship supervisor for a recommendation | social proof |
| connect with classmates, alumni, recruiters, with a short personal note | grows your network |
| post or comment occasionally about what you are learning | shows interest and skill |
| turn on "Open to work" for recruiters only, if you wish | recruiters can find you |

:::tip
Keep one "master" resume with everything you have done, and make a tailored one-page version for each application. Match the job description's keywords where they honestly describe you.
:::
