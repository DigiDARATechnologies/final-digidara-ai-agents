## Write, then edit

Do not try to write perfectly in the first attempt. Get your ideas down, take a short break, then **edit**.

| Step | Focus |
| --- | --- |
| **1. Write** | get the message out; do not worry about wording |
| **2. Structure** | is the main point first? is the order logical? |
| **3. Cut** | remove words, sentences and paragraphs that do not help |
| **4. Simplify** | use plain words and short sentences |
| **5. Proofread** | fix spelling, grammar, names, numbers, formatting |

## Use plain words

| Instead of | Write |
| --- | --- |
| utilise | use |
| commence | start |
| in order to | to |
| at this point in time | now |
| due to the fact that | because |
| prior to | before |
| kindly do the needful | please do [say exactly what] |
| revert back | reply |
| ascertain | find out |
| in the event that | if |
| a large number of | many |
| with regard to / with reference to | about |

Phrases such as "kindly do the needful" and "revert back" are common in Indian office English, but they are vague or incorrect. Say exactly what you want.

## Shorten sentences

:::example Shorten
**Before (34 words):** "I am writing this email to let you know that we have made a decision to postpone the meeting that was originally scheduled for Monday to a later date because of the fact that several team members will not be available."

**After (16 words):** "We are postponing Monday's meeting because several team members are unavailable."
:::

A good guide: aim for about **15 to 20 words** per sentence, and vary the length so that it does not sound mechanical.

## Active voice is usually clearer

| Passive | Active |
| --- | --- |
| The report was completed by the team. | The team completed the report. |
| Mistakes were made. | I made mistakes. (honest and direct) |
| It has been decided that the fee will be increased. | The college will increase the fee. |

Passive is not wrong, and is useful when the doer is unknown or unimportant ("The server was restarted at 2 am"). But too much passive sounds vague and cold.

## Grammar mistakes to watch for

| Wrong | Right | Rule |
| --- | --- | --- |
| I have **a** MBA degree. | I have **an** MBA degree. | `an` before a vowel *sound* (M is pronounced "em") |
| He **don't** know. | He **doesn't** know. | `doesn't` with he, she, it |
| I **am having** a laptop. | I **have** a laptop. | verbs of possession are rarely used in the continuous form |
| I am **knowing** the answer. | I **know** the answer. | `know`, `understand`, `like`, `want` are not used in continuous form |
| **Myself** Priya. | **I am** Priya. / **My name is** Priya. | `myself` needs a pattern like "I did it myself" |
| I will **discuss about** it. | I will **discuss** it. | `discuss` already includes "about" |
| **Your's** sincerely | **Yours** sincerely | no apostrophe in `yours`, `hers`, `its` |
| **Its** a good plan. | **It's** a good plan. | `it's` = it is; `its` shows ownership |
| **Less** students came. | **Fewer** students came. | `fewer` for things you can count |
| **Between** the three of us | **Among** the three of us | `between` two, `among` more than two |
| I went **for** a picnic **yesterday night**. | I went on a picnic **last night**. | natural time expressions |
| **Prepone** the meeting | **Move the meeting earlier** | `prepone` is common in India but not understood in many places |
| **Cousin sister / cousin brother** | **cousin** | `cousin` is already neutral |
| **Pass out** from college | **Graduate** from college | `pass out` can mean "faint" elsewhere |

## Punctuation that matters

| Mark | Use | Example |
| --- | --- | --- |
| **Comma** | separates items and joins clauses | `I need a pen, a notebook and a laptop.` |
| **Full stop** | ends a sentence | one idea, one full stop |
| **Apostrophe** | possession and contractions | `Priya's report`, `don't` |
| **Capital letters** | start of sentences, names, `I` | `I will meet Mr Rao on Monday.` |
| **Question mark** | direct questions only | `Could you send the file?` |

Avoid three or more exclamation marks and ellipses (...) in professional writing.

## Proofreading checklist

| Check | How |
| --- | --- |
| **Names** | spell the recipient's and company's name exactly right |
| **Numbers, dates, amounts** | read each one twice; wrong numbers cost the most |
| **Spelling** | use spell-check, but also read it: spell-check misses `form` for `from` |
| **Attachments and links** | present and working |
| **Consistency** | same date format, same spelling style (British or American) |
| **Tone** | read aloud |

Techniques that help: read the text **aloud**, read it **backwards** (sentence by sentence) to catch typing mistakes, change the font or print it, or ask someone to read it.

:::tip
Tools such as a spell-checker, Grammarly-style checkers and AI assistants are helpful for catching errors, but you are still responsible for the message. Do not paste confidential company information into public tools.
:::
